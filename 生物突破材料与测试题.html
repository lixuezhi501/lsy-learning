第一部分：知识结构图

以下以缩进列表方式展示七年级上下册核心章节的知识框架，建议结合课本逐单元对照复习。重要概念用加粗标出，易错点用强调标注。

一、七年级上册

1. 细胞的结构和功能

细胞是生命活动的基本单位
动物细胞的结构
细胞膜：控制物质进出细胞
细胞质：生命活动的主要场所，含有线粒体等细胞器
细胞核：含有遗传物质（DNA），控制细胞的生命活动
植物细胞的结构（与动物细胞的区别）
除具有细胞膜、细胞质、细胞核外，还具有：
细胞壁：由纤维素构成，起保护和支持作用
叶绿体：光合作用的场所（非所有植物细胞都有，如根尖细胞无叶绿体）
液泡：中央大液泡中含有细胞液，溶解多种物质
细胞学说（北师大版知识点）
一切生物体都是由细胞构成（病毒除外）
细胞是生物体结构和功能的基本单位
细胞来自已有细胞的分裂（新细胞只能由老细胞分裂产生）
细胞分裂与生长
细胞分裂：细胞核先分裂→细胞质分裂→形成两个新细胞
细胞分化：形成不同形态和功能的细胞群→组织

2. 生物体的结构层次

从细胞到生物体
组织：形态相似、结构和功能相同的细胞联合在一起
动物组织（4种）
上皮组织：覆盖体表和器官内表面，有保护功能
结缔组织：种类多，如骨组织、血液、脂肪组织等，有支持、连接等功能
肌肉组织：由肌细胞构成，能收缩和舒张，产生运动
神经组织：由神经细胞（神经元）构成，感受刺激、传导兴奋
植物组织（4种）
分生组织：细胞小、核大、壁薄、质浓，分裂能力强
保护组织：覆盖植物体表面（如表皮），有保护功能
营养组织：细胞壁薄、液泡大，储存营养物质
输导组织：导管（运输水和无机盐）、筛管（运输有机物）
器官：不同组织按一定次序联合形成
动物器官：如胃由上皮组织、肌肉组织、结缔组织、神经组织构成
植物器官（六大器官）：根、茎、叶（营养器官）；花、果实、种子（生殖器官）
系统：能共同完成某一生理功能的多个器官的总称（动物有系统，植物无系统）
结构层次总结
动物体：细胞 → 组织 → 器官 → 系统 → 动物体
植物体：细胞 → 组织 → 器官 → 植物体

3. 光合作用与呼吸作用

光合作用
场所：叶绿体（叶肉细胞中）
条件：必需要有光，以光能作能源
原料：二氧化碳 + 水
产物：有机物（主要是淀粉）+ 氧气
过程：将无机物合成有机物，将光能转化为化学能储存在有机物中
意义：①为自身提供有机物和能量 ②为人和动物提供食物和氧气
呼吸作用（与光合作用相反的过程）
场所：线粒体（所有活细胞均有）
条件：有光无光都可进行
原料：有机物 + 氧气
产物：二氧化碳 + 水
实质：分解有机物，释放能量
意义：为生命活动提供能量
蒸腾作用（北师大版上册知识点）
概念：水分以气体状态从植物体内散失到大气中的过程
主要器官：叶（通过气孔）
意义：①促进水和无机盐的运输 ②降低植物体温度 ③提高大气湿度，调节气候

4. 生态系统及其组成

生态系统的概念
在一定的空间范围内，生物与环境所形成的统一整体
范围：有大有小，一片森林、一个池塘都可视为一个生态系统
生态系统的组成
非生物部分：阳光、空气、水、温度、土壤等
生物部分：
生产者：绿色植物，通过光合作用制造有机物
消费者：动物，直接或间接以植物为食
分解者：细菌、真菌等，将有机物分解成无机物
食物链与食物网
食物链：各种生物之间形成吃与被吃的关系（捕食关系）
书写规则：①起点必须是生产者 ②箭头指向取食者 ③不包括非生物部分和分解者
食物网：多条食物链交错连接形成
营养级越高，生物数量越少；有害物质沿食物链逐级积累
生态系统的自动调节能力
生态系统具有一定的自动调节能力，但有一定限度
生物种类越多，食物网越复杂，自动调节能力越强
森林生态系统的自动调节能力 > 草原生态系统 > 农田生态系统

二、七年级下册

5. 消化系统

人体需要的主要营养物质
供能物质：糖类、脂肪、蛋白质
非供能物质：水、无机盐、维生素
消化系统的组成
消化道：口腔 → 咽 → 食道 → 胃 → 小肠 → 大肠 → 肛门
消化腺：
唾液腺：分泌唾液，含唾液淀粉酶（消化淀粉）
胃腺：分泌胃液，含胃蛋白酶（消化蛋白质）和盐酸
肝脏：人体最大的消化腺，分泌胆汁，不含消化酶，起乳化脂肪作用
胰腺：分泌胰液，含多种消化酶（消化糖类、蛋白质、脂肪）
肠腺：分泌肠液，含多种消化酶
三大营养物质的消化过程（高频考点）
淀粉：口腔（唾液淀粉酶）→ 麦芽糖 → 小肠 → 葡萄糖
蛋白质：胃（胃蛋白酶）→ 多肽 → 小肠 → 氨基酸
脂肪：小肠（胆汁乳化 + 胰液肠液消化）→ 脂肪酸 + 甘油
小肠与消化吸收功能相适应的结构特点
长：约 5-6 米，增加了食物停留时间
有皱襞和小肠绒毛：大大增加内表面积
小肠绒毛壁薄（仅一层上皮细胞）
绒毛内有丰富的毛细血管和毛细淋巴管

6. 循环系统

血液的组成
血浆：运输血细胞、养料和废物
红细胞：无细胞核，含血红蛋白，运输氧气
白细胞：有细胞核，吞噬病菌，起防御作用
血小板：无细胞核，促进止血和凝血
血管的类型（比较记忆：动脉/静脉/毛细血管）
动脉：管壁厚、弹性大、血流速度快，将血液从心脏送往全身
静脉：管壁薄、弹性小、血流速度慢、有静脉瓣，将血液从全身送回心脏
毛细血管：管壁极薄（一层细胞）、内径极小、血流最慢，物质交换的场所
心脏的结构
位置：胸腔中部偏左，两肺之间
四腔：左心房、左心室、右心房、右心室（上房下室）
瓣膜：房室瓣（心房和心室之间）、动脉瓣（心室和动脉之间），保证血液单向流动
左心室壁最厚——左心室射血距离最远（体循环）
血液循环的途径
体循环：左心室 → 主动脉 → 全身各处毛细血管 → 上/下腔静脉 → 右心房
过程中：血液由动脉血变为静脉血
肺循环：右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房
过程中：血液由静脉血变为动脉血
区分动脉血与静脉血：看含氧量，不是看流经的血管！动脉血含氧量高、呈鲜红色；静脉血含氧量低、呈暗红色

7. 呼吸系统

呼吸系统的组成
呼吸道：鼻 → 咽 → 喉 → 气管 → 支气管
功能：保证气体通畅，使空气温暖、湿润、清洁
咽是呼吸和消化的共同通道（会厌软骨控制开关）
肺：呼吸系统的主要器官，气体交换的场所
肺泡：数量多、壁薄（一层细胞）、外包丰富的毛细血管
肺泡壁和毛细血管壁都只有一层上皮细胞——有利于气体交换
呼吸运动
吸气：肋间肌和膈肌收缩→胸廓扩大→肺扩张→肺内气压降低→气体入肺
呼气：肋间肌和膈肌舒张→胸廓缩小→肺回缩→肺内气压升高→气体出肺
气体交换
肺泡内的气体交换：肺泡与血液之间（氧气进入血液，二氧化碳进入肺泡）
组织里的气体交换：血液与组织细胞之间（氧气进入细胞，二氧化碳进入血液）

8. 泌尿系统

泌尿系统的组成
肾脏（形成尿液的器官）→ 输尿管（输送尿液）→ 膀胱（暂时储存尿液）→ 尿道（排出尿液）
肾单位——肾脏的结构和功能基本单位
每个肾脏约有 100 万个肾单位
肾小体：肾小球（毛细血管球）+ 肾小囊
肾小管：周围有丰富的毛细血管
尿的形成过程（高频考点）
第一步：肾小球和肾小囊内壁的过滤作用→ 形成原尿（约150升/天）
血液中的血细胞和大分子蛋白质不能被过滤→仍留在血液中
原尿成分：水、无机盐、尿素、葡萄糖
第二步：肾小管的重吸收作用→ 形成尿液（约1.5升/天）
肾小管将全部葡萄糖、大部分水、部分无机盐重新吸收回血液
尿液成分：水、无机盐、尿素
比较：血液→原尿→尿液，葡萄糖含量：有→有→无
排泄途径
肾脏排出尿液（主要途径，排出大部分水和尿素等代谢废物）
皮肤排出汗液（排出部分水、无机盐、少量尿素）
肺排出二氧化碳和少量水蒸气

9. 神经系统

神经系统的组成
中枢神经系统：脑（大脑、小脑、脑干）和脊髓
周围神经系统：脑神经（12对）和脊神经（31对）
神经元（神经细胞）——神经系统结构和功能的基本单位
细胞体：代谢和营养中心
树突：短而多，接受刺激、将兴奋传向细胞体
轴突：长而少，将兴奋从细胞体传出
神经纤维：轴突或长的树突及其外面包裹的髓鞘
反射和反射弧
反射：神经调节的基本方式
反射弧：完成反射活动的结构基础（5个环节缺一不可）
感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器
反射类型
非条件反射：生来就有，如缩手反射、眨眼反射、膝跳反射
条件反射：后天学习获得，在非条件反射基础上建立，如谈虎色变、望梅止渴
眼与视觉
眼球结构：角膜→瞳孔→晶状体→玻璃体→视网膜（成像）
近视眼：晶状体曲度过大或眼球前后径过长→物像落在视网膜前方
矫正：配戴凹透镜
耳与听觉
外耳：耳廓、外耳道（收集和传送声波）
中耳：鼓膜、听小骨（传导和放大声波）
内耳：耳蜗（听觉感受器）、前庭和半规管（位置觉感受器）

10. 生殖与发育

男性生殖系统
主要性器官：睾丸——产生精子、分泌雄性激素
附睾：储存和输送精子
输精管：输送精子
附属腺：精囊腺、前列腺（分泌黏液）
女性生殖系统
主要性器官：卵巢——产生卵细胞、分泌雌性激素
输卵管：输送卵细胞，受精的场所
子宫：胚胎发育的场所（孕育胎儿）
阴道：精子进入通道、胎儿产出通道
受精与发育
受精卵的形成：精子和卵细胞在输卵管内结合形成受精卵
胚胎发育：受精卵不断分裂→植入子宫→胚胎在子宫内发育
胎儿与母体的物质交换：通过胎盘和脐带实现（不是直接交换）
分娩：胚胎发育约38周（约266天）后产出体外
青春期发育特点（北师大版七年级下册）
身高、体重迅速增长（青春期发育的显著特点）
神经系统和心、肺功能明显增强
性器官迅速发育成熟，出现第二性征
开始出现生殖能力

第三部分：重点图例说明

识图题是七年级生物考试的必考题型，也是学生失分的主要区域。以下是北师大版教材中常考的 5 种核心图，请仔细阅读文字描述，在脑海中形成图像，并记住各结构名称及其功能。

图例一：动物细胞结构图

图形描述：画面主体为一个近似圆形的动物细胞剖面图。从外向内由三层结构组成。

  • 最外层（①）：细胞膜 — 极薄的一层膜，包裹细胞。功能：控制物质进出细胞，保护细胞内部结构。
  • 中间填充部分（②）：细胞质 — 细胞膜以内、细胞核以外的胶状物质，含有许多肉眼看不到的微小结构（如线粒体）。功能：生命活动的重要场所，细胞内化学反应在此进行。
  • 中央球形结构（③）：细胞核 — 近似球形，颜色较深，位于细胞近中央处。功能：含有遗传物质，控制细胞的生命活动和遗传。

注意：动物细胞没有细胞壁、叶绿体和大型液泡。这三点是区分动物细胞和植物细胞图像的关键。

图例二：植物细胞结构图

图形描述：画面主体为一个长方形或多边形的植物细胞剖面图（常见素材有洋葱表皮细胞、叶肉细胞等），比动物细胞结构更为复杂。

  • 最外层（①）：细胞壁 — 较厚的方形外框，位于细胞膜之外。功能：起保护和支持作用，使植物细胞保持固定的形状。
  • 紧贴细胞壁内侧（②）：细胞膜 — 极薄，在光学显微镜下通常看不到。功能：控制物质进出。
  • 细胞内填充物质（③）：细胞质 — 占据细胞大部分空间。功能：进行生命活动的主要场所。
  • 中央较大球形结构（④）：细胞核 — 通常位于细胞的一侧（被大液泡挤向边缘）。功能：含遗传物质，控制生命活动。
  • 绿色椭圆形颗粒（⑤）：叶绿体 — 散布在细胞质中的多个绿色小颗粒。功能：进行光合作用。注意：非绿色部分（如根尖、洋葱表皮细胞）不含叶绿体。
  • 占据大部分空间（⑥）：液泡 — 一个或多个大型透明囊状结构，内部充满细胞液。功能：储存营养物质和代谢产物，维持细胞内环境。

对比记忆口诀："动物三件套（膜、质、核），植物六件宝（外加壁、绿、泡）。"

图例三：人体消化系统组成图

图形描述：画面为人体上半身剖面图，用粗线条画出从口腔到肛门的完整消化道和附属消化腺。消化道为一条弯弯曲曲的管道，消化腺以团块状附着在消化道周围。

  • 口腔（①） — 最上方开口处，内部有牙齿和舌。功能：将食物嚼碎，唾液与食物混合，初步消化淀粉。
  • 咽（②） — 口腔后方的管道分叉处。功能：食物和空气的共同通道。
  • 食道（③） — 咽下方连接胃的细长管道。功能：将食物从咽部推向胃（通过蠕动）。
  • 胃（④） — 位于左上腹的囊状结构，形状如弯月。功能：暂时储存食物，初步消化蛋白质，通过胃壁蠕动将食物与胃液混合形成食糜。
  • 小肠（⑤） — 曲折盘绕在腹中的最长管道（5-6米）。功能：消化和吸收的主要场所，三大营养物质在此完成消化并被吸收进入血液。
  • 大肠（⑥） — 围绕小肠外侧的较粗管道。功能：吸收水分和无机盐，形成粪便。
  • 肝脏（⑦） — 附着在胃上方的大块器官，人体最大的消化腺。功能：分泌胆汁（不含消化酶），乳化脂肪。
  • 胰腺（⑧） — 位于胃后方，贴近小肠起始处。功能：分泌胰液，含多种消化酶，消化糖类、蛋白质和脂肪。

易错提醒：唾液腺和肠腺在图上通常以较小的附属结构标注在口腔旁和小肠壁上。

图例四：血液循环途径图（体循环 + 肺循环）

图形描述：画面以心脏为中心，用红色箭头表示动脉血（含氧量高），蓝色箭头表示静脉血（含氧量低）。血管用不同粗细的管道表示——主动脉最粗，毛细血管最细。

体循环（红色变蓝色）：

  • 起点：左心室 — 心脏左下最大的腔室，收缩时将血液泵入主动脉
  • 主动脉 — 人体最粗的动脉血管，从心脏延伸出
  • 身体各部分毛细血管网 — 遍布全身的微小血管网，在此血液与组织细胞之间进行物质交换（氧气和营养物质进入细胞，二氧化碳和代谢废物进入血液）
  • 上/下腔静脉 — 将全身血液收集并送回心脏
  • 终点：右心房 — 心脏右上方的腔室

肺循环（蓝色变红色）：

  • 起点：右心室 — 将血液泵入肺动脉
  • 肺动脉 — 含静脉血的动脉（唯一含静脉血的动脉）
  • 肺部毛细血管网 — 包裹在肺泡周围的毛细血管，在此进行气体交换
  • 肺静脉 — 含动脉血的静脉（唯一含动脉血的静脉）
  • 终点：左心房 — 心脏左上方的腔室

血液循环的意义：不断供给组织细胞所需的氧气和营养物质，及时运走二氧化碳等代谢废物。

图例五：生态系统食物链/食物网示意图

图形描述：画面展示一个池塘或草原生态系统，用箭头连接各种生物表示"谁被谁吃"的关系。箭头方向指向取食者。

例：草原生态系统食物网

画面上从左到右排列生物：草（左下角，数量最多，图例最大最密）→ 兔 → 鹰（右上角，数量最少）。多条食物链交织成网：

  • 草 → 兔 → 鹰
  • 草 → 鼠 → 蛇 → 鹰
  • 草 → 昆虫 → 青蛙 → 蛇 → 鹰

图示要点：

  • 箭头方向：从被吃者指向吃者（即从低级营养级指向高级营养级）。
  • 起点必须是生产者（绿色植物），不能以消费者或非生物部分开头。
  • 食物链中不含分解者和非生物部分。
  • 越靠近食物链顶端，生物的数量越少（呈"金字塔"形分布）。
  • 如果有毒有害物质进入生态系统，会沿食物链逐渐积累——营养级越高，体内有害物质浓度越高。
  • 若某一种生物数量减少，与该生物有捕食关系的其他生物数量会先后发生链式变化。

常考联动分析：如果蛇被人大量捕杀，鼠的数量会先增多（因为蛇减少），但由于鼠增多消耗的草增加，鼠最终会受到食物限制而逐渐减少——体现了生态系统的自动调节能力。

第 22 题（4分）—— 小肠的结构特点

小肠是消化和吸收的主要场所，从结构上分析：

（1）长度长：成人小肠长约 5-6 米，增加了食物在体内的停留时间。（1分）

（2）有环形皱襞：小肠内壁有环形的皱襞，增大了内表面积。（1分）

（3）有丰富的小肠绒毛：皱襞表面又具有密集的指状突起——小肠绒毛，进一步扩大表面积。（1分）

（4）小肠绒毛壁薄且血管丰富：绒毛壁仅由一层上皮细胞构成，绒毛内有丰富的毛细血管和毛细淋巴管，有利于营养物质被快速吸收进入血液循环。（1分）

评分要点：四处结构特点，每点 1 分。关键词：长、皱襞、小肠绒毛、壁薄/毛细血管丰富。表述通顺、逻辑正确即给分。

第 23 题（6分）—— 尿液的形成过程

形成过程（4分）：

（1）过滤作用：当血液流经肾小球时，除血细胞和大分子蛋白质外，血液中的水、无机盐、葡萄糖和尿素等小分子物质从肾小球过滤到肾小囊腔中，形成原尿。（2分，答出"过滤"和"血细胞/大分子蛋白质不能过滤"各 1 分）

（2）重吸收作用：原尿流经肾小管时，其中对人体有用的物质（如全部葡萄糖、大部分水和部分无机盐）被肾小管重新吸收回血液，剩下的水、无机盐、尿素等形成尿液。（2分，答出"重吸收"和"葡萄糖全部被重吸收"各 1 分）

成分比较（2分）：

血液中含有血细胞、大分子蛋白质、水、无机盐、葡萄糖、尿素等。（1分）

原尿不含血细胞和大分子蛋白质，但含有水、无机盐、葡萄糖、尿素。

尿液不含葡萄糖（正常情况），主要成分为水、无机盐、尿素。（1分，点出"原尿有葡萄糖、尿液无葡萄糖"即给分）

评分要点：过滤作用和重吸收作用各 2 分（能写清过程并准确使用术语）；成分比较 2 分（能说清楚三种液体的成分区别）。共 6 分。

第 24 题（4分）—— 结构层次

（1）动物体的结构层次从微观到宏观为：细胞 → 组织 → 器官 → 系统 → 动物体。（2分，层次顺序完全正确给 2 分，每漏写/错写 1 项扣 1 分，最低 0 分）

（2）一片森林中的所有生物不是一个"组织"。（1分，判断正确即给分）

（3）理由："组织"是由形态相似、结构和功能相同的细胞联合在一起形成的细胞群；而一片森林中的所有生物包含了不同种类的生物体，是生态系统层面的概念，不是组织层面的概念。（1分，能区分"组织"和"生态系统"两个概念即给分）

学习建议

李思源同学：生物学科的提分关键在于记忆 + 理解 + 识图三者的结合。建议你：

  1. 每日晨读术语表：每天朗读 5-10 个术语及其定义，直到闭上眼睛能脱口而出。
  2. 画图辅助记忆：在读第三部分图例说明时，拿笔在草稿纸上把结构画出来并标注名称——这是攻克识图题的最好方法。
  3. 错题回炉：做错的题不要只改答案，要翻回课本对应的知识点重新学习，把相关知识点串联起来。
  4. 建立知识联系：例如在学习消化系统时，同时想一下消化的营养物质被吸收后进入哪里（循环系统），废物从哪里排出（泌尿系统）。把各系统串成一张网。
  5. 专心对待简答题：简答题是拉开分数差距的关键，平时多练习用专业术语书写答案，避免用口语化表达。
