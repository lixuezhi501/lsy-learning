第一部分：知识结构图

一、七年级上册

第一章　让我们走进地理
1. 地图三要素
比例尺 = 图上距离 / 实际距离（化为统一单位后计算）
比例尺三种形式：数字式（1:100000）、线段式、文字式
比例尺大小：分母越大，比例尺越小，表示范围越大、内容越简略
方向判定：一般地图"上北下南左西右东"；有指向标按指向标；经纬网图按经纬线定方向
图例与注记：地图上表示各种地理事物的符号
2. 地图的种类
自然地图：地形图、气候图、水文图等
社会经济地图：人口图、交通图、工业图等
3. 地形图的判读
海拔：某地高出海平面的垂直距离
相对高度：某地高出另一地的垂直距离
等高线地形图：等高线越密坡越陡，越疏坡越缓
山顶、山脊、山谷、鞍部、陡崖的等高线特征
分层设色地形图：绿色平原、黄色丘陵、棕色高原山地
第二章　地球的面貌
1. 地球的形状与大小
认识过程：天圆地方→月食推测→麦哲伦环球航行→卫星照片
地球是一个两极稍扁、赤道略鼓的不规则球体
平均半径约6371千米，赤道周长约4万千米，表面积约5.1亿平方千米
2. 经纬网
纬线：与赤道平行的圆，指示东西方向，长度从赤道向两极递减
纬度：0°~90°，赤道0°，北纬N、南纬S
经线：连接南北两极的半圆，指示南北方向，长度都相等（约2万千米）
经度：0°~180°，本初子午线0°，东经E、西经W
南北半球分界线：赤道（0°纬线）
东西半球分界线：20°W 和 160°E 组成的经线圈
低纬度（0°~30°）、中纬度（30°~60°）、高纬度（60°~90°）
3. 地球的运动
自转：绕地轴自西向东转，周期约24小时，产生昼夜交替和时间差异
公转：绕太阳自西向东转，周期一年，产生四季变化和昼夜长短变化
地轴倾斜约23.5°，公转时地轴倾斜方向不变
太阳直射点在南北回归线之间移动（23.5°N~23.5°S）
二分二至：春分(3/21)、夏至(6/22)、秋分(9/23)、冬至(12/22)
五带划分：热带、北温带、南温带、北寒带、南寒带
4. 海陆分布与变迁
地球表面：海洋71%，陆地29%（"七分海洋三分陆地"）
七大洲：亚洲、非洲、北美洲、南美洲、南极洲、欧洲、大洋洲
四大洋：太平洋、大西洋、印度洋、北冰洋
洲界：亚欧分界（乌拉尔山脉-乌拉尔河-里海-大高加索山脉-黑海-土耳其海峡）
亚非分界（苏伊士运河）、南北美分界（巴拿马运河）
板块构造学说：六大板块（亚欧、非洲、美洲、太平洋、印度洋、南极洲）
板块张裂形成裂谷/海洋（如东非大裂谷、大西洋）
板块碰撞形成山脉/海沟（如喜马拉雅山、马里亚纳海沟）
两大火山地震带：环太平洋火山地震带、地中海-喜马拉雅火山地震带
第三章　世界的居民
1. 人口
世界人口增长：18世纪前缓慢，工业革命后加快，20世纪以来迅猛增长
人口自然增长率 = 出生率 - 死亡率
人口密度 = 某地人口数 / 某地面积（人/平方千米）
人口问题：人口增长过快（资源短缺、环境恶化、就业困难）；人口增长过慢（劳动力不足、人口老龄化）
人口分布：亚洲东部和南部、欧洲西部、北美洲东部人口稠密
2. 人种
白色人种：欧洲、北美洲、大洋洲、西亚、北非
黄色人种：亚洲东部、美洲印第安人
黑色人种：非洲中部和南部、大洋洲
3. 语言与宗教
联合国工作语言：汉语（使用人数最多）、英语（使用范围最广）、法语、俄语、西班牙语、阿拉伯语
三大宗教：基督教（信徒最多）、伊斯兰教、佛教
4. 聚落
城市聚落：人口密集、建筑高大、交通便利
乡村聚落：人口稀疏、以农业为主
聚落形成条件：水源充足、地形平坦、土壤肥沃、气候适宜、交通便利
第四章　世界的气候
1. 天气与气候
天气：短时间、多变（如"今天晴"）
气候：长时间、稳定（如"昆明四季如春"）
2. 气温分布规律
纬度因素：从低纬向高纬递减（赤道高温，两极低温）
海陆因素：同纬度夏季陆地气温高于海洋，冬季相反
地形因素：海拔每升高100米，气温下降约0.6℃
世界最热的地方：撒哈拉沙漠地区
世界最冷的地方：南极地区
3. 降水分布规律
赤道附近降水多，两极地区降水少
南北回归线两侧：大陆东岸降水多，大陆西岸降水少
中纬度地区：沿海降水多，内陆降水少
迎风坡降水多，背风坡降水少
4. 主要气候类型
热带雨林气候：全年高温多雨（赤道附近，如新加坡）
热带草原气候：全年高温，分干湿两季（非洲热带草原）
热带沙漠气候：全年高温少雨（撒哈拉沙漠）
热带季风气候：全年高温，分旱雨两季（印度半岛）
地中海气候：夏季炎热干燥，冬季温和多雨（地中海沿岸）
温带海洋性气候：全年温和湿润（欧洲西部）
温带季风气候：夏季高温多雨，冬季寒冷干燥（中国北方）
温带大陆性气候：冬冷夏热，全年降水少（亚欧大陆内部）
亚寒带针叶林气候：冬季漫长寒冷，夏季短促温暖
寒带气候（苔原、冰原）：全年严寒
高原山地气候：垂直变化明显（青藏高原）
5. 影响气候的主要因素
纬度位置、海陆位置、地形因素
第五章　世界的发展差异
1. 发展水平差异
发达国家：欧洲、北美、日本、澳大利亚等，以第三产业为主
发展中国家：亚洲、非洲、拉丁美洲，以第一产业为主
2. 国际合作
南北对话：发达国家与发展中国家之间的政治经济商谈
南南合作：发展中国家之间的互助合作
国际合作组织：联合国（UN）、世界贸易组织（WTO）等

二、七年级下册

第一章　认识大洲
1. 亚洲（重点）
位置：跨经度最广的大洲，东临太平洋，南临印度洋，北临北冰洋
地形：以高原山地为主，平均海拔最高；中部高四周低，河流呈放射状
主要高原：青藏高原（世界最高）、帕米尔高原、伊朗高原、德干高原
主要平原：西西伯利亚平原、华北平原、恒河平原
气候：复杂多样，大陆性强，季风气候显著
主要气候类型：温带大陆性气候（分布最广）、热带季风气候、亚热带季风气候、温带季风气候
主要河流：长江、黄河、湄公河（澜沧江）、恒河、印度河、鄂毕河
2. 非洲
位置：东临印度洋，西临大西洋，赤道横贯中部
地形：高原大陆，地势东南高西北低
气候：以热带气候为主，赤道附近为热带雨林，向两侧对称分布热带草原和热带沙漠
尼罗河：世界最长河流，自南向北注入地中海
撒哈拉以南非洲：黑种人故乡，单一商品经济问题
3. 北美洲
地形：三大南北纵列带（西部高山、中部平原、东部低矮山地）
气候：温带大陆性气候为主，受地形影响显著
密西西比河：世界第四长河
五大湖：世界最大淡水湖群
4. 南美洲
地形：西部安第斯山脉（世界最长），东部平原高原相间
气候：热带气候为主，世界最大热带雨林区（亚马孙平原）
亚马孙河：世界流量最大、流域面积最广的河流
第二章　了解地区
1. 东南亚
位置：亚洲与大洋洲、太平洋与印度洋之间的"十字路口"，马六甲海峡是咽喉要道
组成：中南半岛 + 马来群岛
地形：中南半岛山河相间、南北纵列；马来群岛多火山地震
气候：热带季风气候（中南半岛，旱雨两季）、热带雨林气候（马来群岛，全年高温多雨）
农业：水稻（主食）、橡胶（泰国世界最大）、油棕（马来西亚）、蕉麻（菲律宾）
人口城市：集中在大河沿岸平原和河口三角洲
2. 中东
位置：两洋三洲五海之地（印度洋、大西洋；亚欧非三洲；地中海、红海、阿拉伯海、黑海、里海）
石油：储量最大、产量最大、出口量最大，主要运往东亚、欧洲西部、北美洲
水资源：匮乏，热带沙漠气候为主，河流稀少
宗教：伊斯兰教发源地，耶路撒冷是三大宗教圣地
3. 欧洲西部
位置：中纬度大陆西岸，北临北冰洋，西临大西洋
地形：以平原为主，海岸线曲折，多半岛岛屿
气候：温带海洋性气候为主，全年温和湿润，适合多汁牧草生长
经济：发达国家集中，畜牧业发达
旅游：法国埃菲尔铁塔、英国伦敦塔桥、意大利水城威尼斯等
4. 撒哈拉以南非洲
位置：撒哈拉以南，东临印度洋，西临大西洋
地形：高原大陆，地势由东南向西北倾斜
气候：以热带草原气候为主（全年高温，分干湿两季）
经济：单一商品经济（出口初级产品，进口工业制成品）
人口粮食环境问题：人口增长过快→毁林开荒→环境恶化→粮食短缺
5. 极地地区
南极地区：被太平洋、印度洋、大西洋包围，代表动物企鹅
南极特点：酷寒、干燥、烈风，有煤铁等矿产（说明曾经不在极地）
北极地区：被亚欧北美包围，代表动物北极熊
科考：中国南极科考站（长城站、中山站、昆仑站、泰山站）；最佳科考时间（南半球夏季11月-次年3月）
第三章　走进国家
1. 日本
位置：太平洋西岸岛国，由北海道、本州、四国、九州四大岛组成
地形：多山地丘陵，平原狭小（关东平原最大），多火山地震（富士山）
气候：温带季风气候和亚热带季风气候，海洋性明显
经济：发达，进口原料出口工业产品，工业区集中在太平洋沿岸
2. 印度
位置：南亚次大陆，北靠喜马拉雅山脉，南临印度洋
地形：北部山地、中部恒河平原、南部德干高原
气候：热带季风气候，6-9月雨季（西南季风），10-5月旱季
水旱灾害：西南季风不稳定，来得早退得晚→洪灾；来得晚退得早→旱灾
农业：水稻（东北部）、小麦（西北部）、黄麻（恒河三角洲）、棉花（德干高原西北部）
服务外包产业："世界办公室"
3. 俄罗斯
位置：跨亚欧两洲，世界面积最大国家
地形：西部平原（东欧平原、西西伯利亚平原），中部高原（中西伯利亚高原），东部山地
气候：温带大陆性气候为主，冬季漫长寒冷
资源：自然资源丰富（石油、天然气、森林）
工业：重工业发达，轻工业薄弱
交通：铁路为主（西伯利亚大铁路），欧洲部分密集
4. 澳大利亚
位置：南半球独占一个大陆
地形：东部山地（大分水岭）、中部平原（大自流盆地）、西部高原
气候：呈半环状分布，热带面积广
经济："骑在羊背上"（羊毛产量出口第一）、"坐在矿车上"（矿产出口）
特有动物：袋鼠、鸸鹋、考拉（独占一个大陆，长期孤立，进化缓慢）
5. 美国
位置：本土位于北美洲中部，东临大西洋，西临太平洋，南临墨西哥湾
地形：三大纵列带（西部高山科迪勒拉山系、中部平原、东部阿巴拉契亚山脉）
农业：地区专业化，玉米带、小麦区、棉花带、乳畜带
工业：东北部（传统工业）、南部（新兴工业）、西部（高新技术）
6. 巴西
位置：南美洲东部，东临大西洋
地形：北部亚马孙平原（世界最大平原），南部巴西高原（世界最大高原）
气候：热带雨林气候（亚马孙平原）、热带草原气候（巴西高原）
亚马孙河：世界流量最大、流域面积最广
经济：南美洲经济最发达国家，咖啡、甘蔗、柑橘产量世界第一
人口城市：集中在东南部沿海

第二部分：核心概念与术语

以下概念是地理考试中高频出现的判断、选择和简答考点，务必准确理解。
比例尺大小比较：分母越大→比例尺越小→表示范围越大→内容越简略。
例：1:100000 比 1:10000 大；图幅相同的两幅地图，比例尺小的表示的实际范围更大。
东西半球分界线：20°W 和 160°E 组成的经线圈。
记忆口诀："小于20度在东半球，大于160度也在东半球"——即 20°W~0°~160°E 为东半球，20°W~180°~160°E 为西半球。
经纬网定方向：经线指示南北方向，纬线指示东西方向。
北纬增大方向为北，南纬增大方向为南；东经增大方向为东，西经增大方向为西。
等高线地形图判读：
地形部位等高线特征
山顶闭合曲线，内高外低
山脊等高线向低处凸出
山谷等高线向高处凸出
鞍部两个山顶之间的低洼处
陡崖等高线重合处（用锯齿符号标注）
板块运动方向： 张裂运动→形成裂谷或海洋（如东非大裂谷将变大洋、红海在扩大、大西洋在扩大）；
碰撞挤压→形成山脉或海沟（如喜马拉雅山由亚欧板块与印度洋板块碰撞形成、地中海在缩小）。
地中海气候特征：夏季炎热干燥，冬季温和多雨。
易错点：地中海气候的雨季在冬季，与季风气候（雨季在夏季）相反。
热带季风 vs 热带草原气候： 两者都是全年高温、分干湿（旱雨）两季。
区别：热带季风气候降水更多（年降水量>1500mm），雨季更集中；热带草原气候降水较少（年降水量500~1500mm）。
分布：热带季风在亚洲南部（印度半岛、中南半岛）；热带草原在非洲、南美洲、澳大利亚。
人口自然增长率：出生率 - 死亡率。
发达国家人口增长慢（甚至负增长），发展中国家人口增长快。
人口自然增长率最高的洲：非洲；最低的洲：欧洲。
南北对话 vs 南南合作： 南北对话 = 发展中国家（南）与发达国家（北）之间的政治经济商谈；
南南合作 = 发展中国家（南）之间的互助合作。
易混淆点提醒：
① "世界跨经度最广的大洲"是南极洲（跨所有经度），不是亚洲。
② "世界面积最大的大洋"是太平洋，"世界跨经度最广的大洋"是北冰洋。
③ "世界最长的河流"是尼罗河（非洲），"世界流量最大的河流"是亚马孙河（南美洲）。

（2）马六甲（1分）。从波斯湾出发→阿拉伯海→印度洋→马六甲海峡→南海→日本。

（3）热带沙漠（1分）｜ 高温少雨（干旱）（1分）。

（4）伊斯兰（1分）。中东是伊斯兰教发源地。

（5）欧（1分）。两洋（印度洋、大西洋）三洲（亚洲、非洲、欧洲）五海（地中海、红海、阿拉伯海、黑海、里海）。

30.（7分）巴西

（1）大西（1分）｜ 平原（亚马孙平原）（1分）｜ 高原（巴西高原）（1分）。

（2）热带雨林能大量吸收二氧化碳、释放氧气，调节全球气候（1分）。

（3）热带雨林（1分）｜ 全年高温多雨（1分）。

（4）气候温和湿润、海上交通便利、开发历史悠久（1分，答出一点即可）。

学习建议

1. 读图能力是关键。地理考试中读图题占比超过50%。重点训练：经纬网定位、等高线判读、气候类型判断、区域地理综合分析。

2. 建立空间概念。不要死记硬背，要在脑中建立"地图思维"——看到"地中海气候"就能想到分布区域和特征。

3. 对比记忆法。热带季风vs热带草原、地中海vs温带季风、发达国家vs发展中国家——通过对比加深理解。

4. 关注因果链条。纬度位置→气温→气候→农业→经济→人口，地理知识是相互关联的，不是孤立的。

5. 每天15分钟读图训练。暑假期间每天花15分钟看地图、做读图题，比集中刷题效果更好。
